# TryHackMe — Cyber Security 101 Study Notes

A complete, modular reference and study guide covering the **14 Modules (53 Rooms)** of the [TryHackMe Cyber Security 101](https://tryhackme.com/path/outline/cybersecurity101) learning path. Each module is organized into its own Markdown file, with individual rooms structured as chapters containing core concepts, command cheat sheets, and practical lab takeaways.

## 🛠️ Key Tools Practiced Across the Path

- **Reconnaissance & Networking:** `nmap`, `tcpdump`, `Wireshark`, `whois`, `dig`, `nslookup`
- **Web & Exploitation:** `Burp Suite`, `gobuster`, `sqlmap`, `hydra`, `Metasploit Framework (msfconsole)`, `netcat`, `socat`
- **Cryptography & Cracking:** `John the Ripper`, `hashcat`, `gpg`, `ssh`, `openssl`
- **Defensive & Malware Analysis:** `Splunk` / `ELK` (SIEM), `ufw`, `iptables`, `Snort` (IDS), `OpenVAS` / `Nessus`, `CyberChef`, `CAPA`, `REMnux`, `FlareVM`
